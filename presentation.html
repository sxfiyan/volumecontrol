Key Objectives & Features

Computer Vision Tracking

  • Live webcam feed acquisition (640x480 resolution)
  • Real-time 21-landmark hand skeleton tracking

Smart System Audio Mapping

  • Euclidean distance mapping to 0% – 100% volume level
  • Exponential Moving Average (EMA) jitter suppression
  • Direct macOS AppleScript & Windows Pycaw volume dispatch

Mathematical Formulation

Euclidean Distance

Calculates distance between Thumb Tip $(x_1, y_1)$ and Index Tip $(x_2, y_2)$:

d = √[(x₂ - x₁)² + (y₂ - y₁)²]

EMA Smoothing Filter

Removes micro-tremor jitter in continuous frames:

V_smooth = α·V_raw + (1 - α)·V_prev
